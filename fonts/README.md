# Bundled fonts

Free bitmap fonts loaded by OctaDraw at start-up. Each file keeps its original
BDF header (name, `COPYRIGHT`). Only a subset of characters is kept: ASCII,
Latin-1 (U+00A0–U+00FF), arrows (U+2190–U+21FF), box drawing and geometric
shapes (U+2500–U+25FF).

| File | Origin | Licence |
|---|---|---|
| `fixed-4x6.bdf` | X11 misc-fixed 4x6 | Public domain (“Public domain font. Share and enjoy.”) |
| `fixed-5x7.bdf` | X11 misc-fixed 5x7 | Public domain |
| `fixed-5x8.bdf` | X11 misc-fixed 5x8 | Public domain |
| `fixed-6x10.bdf` | X11 misc-fixed 6x10 | Public domain |
| `fixed-6x13B.bdf` | X11 misc-fixed 6x13 bold | Public domain |

Your own BDF fonts go in the user font folder (see `OCTADRAW_FONTS`) or through
“Import BDF” in the editor. They are not copied here.
